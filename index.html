Suggested 12–16 Week Path

  1. Weeks 1–2: HLD fundamentals — scalability, availability, networking, databases.
  2. Weeks 3–4: Redis, Kafka, load balancing, API gateway, rate limiting, reliability.
  3. Weeks 5–7: HLD case studies — URL Shortener, Notification, Chat, Payment, E-commerce.
  4. Weeks 8–9: LLD — OOP, SOLID, UML, design patterns.
  5. Weeks 10–12: LLD case studies + Java implementation + concurrency.
  6. Weeks 13–16: Mixed mock interviews, trade-offs, failure scenarios and timed designs.

Interview mindset

Requirements → Scale → APIs → Data model → High-level architecture → Deep dive → Bottlenecks → Failure handling → Trade-offs.

HLD — High Level Design

Prioritize the topics marked High. For every topic, ask: Why do we need it? What problem does it solve? What breaks without it?

LLD — Low Level Design

For Java interviews, practice turning requirements into interfaces, classes, relationships, patterns and production-quality code.

Interview Questions

System Design Case Studies

For each case, practice requirements, scale estimates, APIs, data model, architecture, bottlenecks, failure scenarios and trade-offs.
